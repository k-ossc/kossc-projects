# kossc-projects
한국오픈소스보안커뮤니티(K-OSSC) 회원·회원사의 오픈소스 프로젝트 큐레이션
 
한국오픈소스보안커뮤니티(K-OSSC) 회원과 회원사의 오픈소스 프로젝트를 모아 소개합니다.
원본 저장소는 각 소유자에게 있으며, 이곳은 소개와 연결을 맡습니다.
 
## 회원사 프로젝트
 
| 프로젝트 | 소개 | 분야 | 등재 |
|---|---|---|---|
| [SecLLM](https://sparrow-co-ltd.github.io/SecLLM-Dataset-Portal) | SecLLM은 보안 검사 도구가 찾아낸 소스코드 취약점을 AI가 설명하고 직접 고쳐주도록 만들되, 회사 코드를 외부 서비스로 보내지 않고 자체 서버 안에서 동작하는 작은 모델로 처리할 수 있게 하는 오픈소스 프로젝트입니다. 이를 위해 실제 오픈소스 코드에서 수집한 취약점과 검증된 수정 코드들을 데이터셋으로 공개하고 있으며, 취약점의 발생 맥락과 설명, 고친 방법까지 함께 담아 누구나 학습과 연구에 활용할 수 있습니다. | 취약점 분석·패치 | 2026.9 |
